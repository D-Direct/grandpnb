## Steps:
1. Upload all PNG/JPEG/JFIF files to a batch converter
2. Download the WebP versions
3. Place them in the same directories with .webp extension
4. Delete the old PNG/JPEG/JFIF files
5. Run `npm run build` to test
6. Commit and push
